# React Temperature Controller 🌡️

![Project Preview](./public/images/preview.png)

A simple temperature controller built with **React** and **Vite** as a beginner-friendly practice project.

## Features

- Increase temperature.
- Decrease temperature.
- Dynamic temperature display.
- Conditional CSS styling based on temperature.
- React state management using `useState`.

## Built With

- React
- Vite
- JavaScript
- CSS

## Getting Started

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd react-temperature-controller
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
